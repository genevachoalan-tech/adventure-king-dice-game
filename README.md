## 📖 剧本简介

石泉酒馆里，六位冒险者齐聚一堂。猪头老板巴顿拿出了一份神秘的委托——深入地牢，寻找传说中的龙蛋。红队与蓝队的对抗就此展开！投骰子、走地图、打怪物、捡装备，谁能成为最终的冒险王？

- **人数：** 6 人（+ 1 名 DM / 主持人）
- **类型：** 机制 / 欢乐 / 跑团 / 对抗
- **时长：** 约 5-6 小时
- **难度：** ⭐⭐⭐
- **阵营：** 红队 3 人 vs 蓝队 3 人

## ✨ 功能特色

### 🏠 房间系统
- DM 创建房间，自动生成 6 位数字房间号
- 玩家输入房间号即可加入（无需昵称，直接用角色名）
- **断线重连：** 意外断开后重新输入房间号自动恢复
- DM 创建房间需要身份验证（防止他人乱开）

### 🎪 3v3 圆桌 UI
- 木质圆桌居中，红队左侧、蓝队右侧
- DM 座位在顶部，猪头老板巴顿头像
- 6 个玩家座位环绕圆桌，显示 Q 版萌兽头像、角色名、队伍颜色
- 左侧常驻角色面板，显示血量、金币、装备、技能
- 在线呼吸灯，离线标记

### 🗺️ 双地图系统

#### 逃生地图（24 格竞速）
- 红队蓝队竞速，先到终点获胜
- 格子类型：普通格、怪物格、宝箱格、三叶草事件格、商店格
- 每队共用一个棋子，队长可拖动
- 队长由玩家在加入游戏时讨论指定

#### 地牢地图（两层，对照官方重绘）
- **一层：** 雕像区、商店、怪物、宝箱、三叶草、泉水
- **二层：** 怪物、宝箱、三叶草、泉水、BOSS（龙）
- 红蓝两队从同一雕像出发
- 格子效果标注清晰，DM 手动触发

### 🎲 小游戏系统

#### 抓蛇游戏（48 张牌）
- 玩家翻牌匹配，找到蛇即可得分
- 不透明背景，完全覆盖圆桌
- 玩家自主操作

#### 砸酒桶（玩家自投骰子）
- 上下层金币机制，对照官方规则
- 玩家自己投骰子，DM 无需手动
- 结果自动记录

#### 电子靶盘
- 最终机制使用
- 投骰子命中靶盘得分
- DM 辅助面板显示结果

### ⚔️ 战斗系统（方案 C：DM 强辅助）
- **全部效果 DM 手动触发**，避免自动 bug
- DM 强辅助面板：
  - 伤害计算器（自动计算武器+技能+骰子伤害）
  - 状态管理（中毒、眩晕、护盾等）
  - 效果管理（增益/减益）
  - 回合提醒（当前轮到谁攻击）
  - 怪物管理（血量、技能、状态）
- 玩家选择骰子颜色触发技能，DM 手动结算
- 怪物血量、技能、状态全部 DM 可控

### 🐉 BOSS 战（共享血量）
- 先到的队先打，后到的队加入一起打
- BOSS 血量共享，两队共同输出
- 击败 BOSS 后进入结局投票
- 龙蛋教学战斗（血量 50，练习模式）

### 🍀 三叶草事件（8 个搞笑演绎）
- 全队演绎事件，带辅助台词（怕玩家放不开）
- DM 手动触发，选择红队或蓝队
- 事件内容搞笑欢乐，调节气氛
- 完成后获得奖励

### 🛒 商店系统
- DM 开启商店后，玩家端出现商店入口
- **装备：** 3 金币
- **技能：** 4 金币
- **血量：** 1 金币
- 玩家自主购买，自动装备到对应槽位

### 🎒 装备 / 技能 / 背包系统

#### 装备 4 槽
1. **专属武器**（固定，不可更换，每个角色独有）
2. **主武器**（可更换，主要伤害来源）
3. **副武器 / 护盾 / 宝物**（可更换，辅助效果）
4. **道具**（可更换，消耗品）

#### 技能 4 槽
1. **固定技能 1**（角色自带）
2. **固定技能 2**（角色自带）
3. **可购技能 1**（商店购买）
4. **可购技能 2**（商店购买）

#### 背包 2 槽
- 装备槽满时自动转入背包
- 可从背包装备、丢弃、回收给 DM

### 📜 剧本系统
- 剧本分幕，按阶段解锁
- 「当前任务」红色加粗标注
- 玩家随时可查看自己的剧本
- DM 可查看所有玩家剧本（方便回答问题）
- 结局分离：玩家投票前看不到结局，DM 在投票 tab 手动发放结局 1 / 2

### 🔊 音频系统
- **18 首 BGM**，覆盖各阶段氛围，自动循环
- **DM 权限：** 切换曲目、播放/暂停、音量控制，全端同步
- **玩家权限：** 只能调音量大小
- 多种音效：骰子、战斗、线索揭示、按钮点击、胜利/失败等

### 📝 游戏记录
- 所有重要操作自动记录（+钱、+血、获得装备、战斗结果等）
- 所有玩家可见，实时同步
- DM 可手动添加记录

### 🧪 测试模式
- DM 可一键模拟全部 6 个玩家
- 方便开本前测试完整流程
- 测试模式下 DM 可查看所有玩家剧本和面板

## 🚀 使用方法

### DM（主持人）
1. 打开线上网址
2. 点击「创建房间（DM）」
3. 验证身份后获得 6 位房间号，分享给玩家
4. 玩家加入后，在「玩家管理」中分配角色和队长
5. 通过右侧控制面板推进游戏：
   - **阶段流程：** 推进游戏阶段
   - **玩家管理：** 分配角色、调整血量金币、踢出玩家
   - **商店：** 开启/关闭商店
   - **发牌/线索：** 发放装备、技能、道具、线索
   - **投票：** 发起投票、发放结局
   - **地图：** 查看双地图、触发格子事件
   - **音频：** 控制 BGM 和音效
   - **手册：** 查看组织者手册
   - **效果管理：** 战斗辅助面板（伤害计算、状态管理）
   - **测试工具：** 模拟玩家、快速测试

### 玩家
1. 打开线上网址
2. 点击「加入房间（玩家）」
3. 输入 DM 提供的 6 位房间号
4. 等待 DM 分配角色
5. 分配后即可看到自己的剧本、角色面板、地图
6. 队长可拖动队伍棋子
7. 通过左侧角色面板查看血量、金币、装备、技能
8. 商店开启后可购买装备和技能

## 🎯 游戏流程概览

1. **开场：** 玩家阅读剧本，了解角色背景
2. **酒馆阶段：** 抓蛇游戏、砸酒桶小游戏，赚取金币
3. **逃生通道：** 24 格竞速地图，红队蓝队对抗
4. **地牢一层：** 探索、打怪、捡装备、三叶草事件
5. **地牢二层：** 更难的怪物、泉水回复、最终 BOSS
6. **BOSS 战：** 两队共同击败龙
7. **结局投票：** 投票决定结局，DM 发放对应结局

## 💻 技术说明

- **纯单文件 HTML**，无需服务器，双击即可运行
- **PeerJS P2P** 房间同步，DM 为房间主机
- **localStorage** 断线重连恢复
- 建议使用 Chrome / Edge 浏览器，桌面端体验最佳
- 最小宽度 1024px
- 手机端未做适配，建议桌面端使用

---

## ⚠️ 注意事项

- 房间同步依赖 PeerJS 公共 broker，需要联网使用
- DM 是房间主机，若 DM 关闭页面超过重连时间，房间状态会丢失，建议 DM 保持页面开启
- BGM 跨设备同步为尽力而为级别，可能有轻微延迟
- 建议使用自己的语音软件（Discord / 微信 / 腾讯会议等）进行语音交流
- 战斗系统采用 DM 手动结算模式，DM 需要熟悉规则
- 所有格子事件均为 DM 手动触发，避免自动触发 bug
